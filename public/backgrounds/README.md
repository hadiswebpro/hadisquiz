# Asset placeholders

Place your own background images in this folder using these exact names:

- intro.jpg — welcome and prediction screens
- bloom.jpg — BLOOM world
- echo.jpg — ECHO world
- veil.jpg — VEIL world
- abyss.jpg — ABYSS world
- void.jpg — VOID world

Backgrounds use cover and center positioning. Theme-specific color overlays are in src/themes/themes.css. VOID has a particularly dark overlay.

Music: add intro.mp3, bloom.mp3, echo.mp3, veil.mp3, abyss.mp3 and void.mp3 in public/audio/. Audio does not autoplay; players can enable it with the sound button.

No copyrighted media is bundled. If an asset is absent, its request will return 404 until you supply it.
